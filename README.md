# IconScout Downloader (Educational Use Only)

This script allows you to download icon files from Iconscout using URLs listed in urls.txt.
It is intended for educational use only, not for commercial purposes.

If you plan to use the downloaded assets commercially, please visit the official Iconscout website and purchase a proper license:
https://iconscout.com/


## Features

* Download icons from Iconscout via provided URLs.
* Support for single or multiple URLs.
* Automatically saves files to the downloader folder.
* Works on Windows, Linux, and macOS.

## How to Use
 1. Prepare urls.txt

    Add one or more Iconscout URLs in the file.
    
    Example:
    
    * https://iconscout.com/3d/atm-receipt-4492229
    * https://iconscout.com/3d/document-folder-4492112

Clone the project

```bash
git clone https://github.com/adex-dev/iconscout-downloader.git
```

Go to the project directory

```bash
  cd iconscout-downloader
```
Run Project:

windows :
png download
```bash
  $py main.py
```
animation lottie
```bash
  $py lottie.py
```
linux or Mac : 
png download
```bash
$python3 main.py
```
animation lottie
```bash
  $python3 lottie.py
```
if you want download png
## Output Location
* The downloaded files will be saved in the path_downloader folder. You can find all results there.
